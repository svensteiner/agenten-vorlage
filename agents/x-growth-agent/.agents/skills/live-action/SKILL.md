# Live Action

Formuliere hoechstens eine konkrete Aktion und ihren erwarteten Nachweis. Nutze fuer eine
tatsaechliche Ausfuehrung ausschliesslich die bestehende Marketingbot-Pipeline mit ihren
Browser-, Duplicate-, Quality-, Budget-, Rate-Limit- und Account-Health-Gates. Dieses
Agentenpaket fuehrt selbst keine Live-X-Aktion aus. Unsicherer Versand blockiert jeden Retry.
