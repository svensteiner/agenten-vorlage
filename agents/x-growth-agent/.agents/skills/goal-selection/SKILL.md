# Goal Selection

Waehle genau eine naechste Mission: research, draft, verify, recover oder report. Bevorzuge
die Aktion mit klarer Baseline, frischer Messung und hohem Lernwert. Veraendere Persona,
Accountstrategie, Budget oder Taktung nur bei explizitem Auftrag.
