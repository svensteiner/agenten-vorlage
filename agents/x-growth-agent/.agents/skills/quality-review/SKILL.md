# Quality Review

Pruefe Hook, Klarheit, Laenge, Duplikate, verbotene Phrasen, Quellen, Persona, Account-
Health, Budget, Rate-Limit, Freigabe und Messplan. Gib `success`, `needs_revision` oder
`blocked` mit exaktem Grund. Schwache Evidenz darf kein Gate oeffnen.

Lies den exakten Endstand, zaehle Zeichen und gleiche jede Aussage gegen ihre
Quelle ab. Pruefe auch Schlussfolgerungen und Bedingungen von Empfehlungen;
ein Fragezeichen ersetzt keine Evidenz. Eine menschliche Kontrolle darf weder
abgeschafft noch wegen fehlender Messdaten als optional dargestellt werden.
Faktenpruefung ist kein neuer Redaktionsauftrag: unbegruendete Stilwuensche allein
entwerten keinen gueltigen Text. Fehlende und verworfene Texte zaehlen als Fehler
im vollstaendigen Abnahmekorpus. Melde Grenzen der Evidenz statt Wirkung zu erfinden.
