# Lernkandidaten

Jeder Kandidat beschreibt mindestens `id`, Datum, redigierten Sachverhalt, Ursache,
Korrektur, BMD-Version/Modul, Quellen mit Standdatum, Gültigkeitsbereich, Konfidenz, Autor,
Reviewer und `status: candidate|approved|rejected|superseded`.

Kandidaten verändern keine Laufzeitregeln. Der zuständige `tax-reviewer` prüft Quelle,
Fallübertragbarkeit und Datenschutz. Erst nach expliziter Freigabe darf eine bereinigte
Notiz nach `../approved/` übernommen werden.
