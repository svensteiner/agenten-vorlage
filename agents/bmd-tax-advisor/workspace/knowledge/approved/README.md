# Freigegebene Wissensnotizen

Dieser Ordner enthält ausschließlich redigierte, datierte und durch den zuständigen
Reviewer freigegebene Arbeitshilfen. Jede Notiz nennt Gültigkeitsbereich, BMD-Version/Modul,
Quellen und Reviewer. Zeitabhängiges Steuerrecht wird bei jeder Verwendung gegen die aktuelle
Primärquelle geprüft.

Keine Credentials, IBANs, Steuernummern, vollständigen Belege oder unnötige Personenbezüge.
Ein `approved`-Eintrag ist keine verbindliche Steuerberatung und autorisiert keine Buchung,
Übermittlung, Zahlung oder Mandantenkommunikation.
