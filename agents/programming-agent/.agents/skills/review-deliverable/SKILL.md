# Review the deliverable

Read the acceptance criteria and inspect the current artifact. For code, trace affected
callers and failure paths; for content, verify claims, audience and usability. Validate
what the supplied test evidence actually proves. A successful unit test is not evidence
of deployment or a completed purchase flow.

Return prioritized defects with precise locations and reproducible consequences. Use
needs_revision for defects, blocked for essential unavailable evidence, success for a
supported result. Do not invent a defect to fill a quota. List residual limitations.
