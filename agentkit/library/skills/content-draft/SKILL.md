# Content draft

Extract audience, desired action, channel and supported product claims. Ask only for facts
that materially affect the draft; use stated assumptions for reversible stylistic choices.
Write the actual deliverable. Verify links and claims where source access is available.
Flag placeholders for unavailable facts. Return the draft path and what was checked.
Sending or publication is a separate operation and is not granted by loading this skill.
