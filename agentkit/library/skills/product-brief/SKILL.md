# Product brief

State who needs what and why. Identify the smallest useful deliverable, the existing
constraints and observable acceptance examples. Separate required scope from optional
ideas. Note unresolved assumptions and decisions that need real user evidence. Produce
a brief a developer can implement without inventing the success criteria.
